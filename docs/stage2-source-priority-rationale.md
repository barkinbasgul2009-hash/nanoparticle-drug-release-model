# Stage-2 Source Priority Rationale

## Why these tiers
- **Tier 1 (essential):** without it a major profile module cannot be defined —
  exact formulation, release, primary tissue/penetration data, official regulatory
  formulation/PK, or the release→tissue coupling source.
- **Tier 2 (high):** materially improves quantitative confidence, parameter ranges,
  or independence (benchmarks, alternative datasets, methods).
- **Tier 3 (supporting):** mechanism, environment, EPR/transport context, textbooks.

## Profile logic
- **D is already complete** (Dreher, primary-verified incl. Table 1) → its extra items
  (D2–D7) are benchmarks/validation only (Tier 2–3).
- **A is nearly parameterizable** (Rothe/Iliopoulos/OECD verified) → needs only the
  true Potts–Guy (A4) + model/clearance refs (A5–A7) to firm up.
- **B, E, F are formulation-defined but unverified** → their Tier-1 items (exact
  formulation + release + official PK) are the highest-value downloads.
- **C** hinges on Chen 2024 + its SI (C1) plus an uptake–return model (C2).

## No padding
Every item maps to a specific evidence module (see profile map). Reviews (B5, E2) are
included only for discovery/secondary context and are labelled as such.
