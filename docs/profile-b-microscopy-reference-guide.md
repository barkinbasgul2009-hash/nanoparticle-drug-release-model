# Profile B — Microscopy Reference Collection (lawful, open-licensed)

Design only. Machine-readable: `data/profile-b-microscopy-references.json`. These are
**design references** — analyze visual principles; do not copy protected artwork. **Verify
each file's license before any reuse.**

## Reference-only (principles, not reuse)
- **DermNet NZ** and textbook/atlas figures are proprietary — use as **visual-principle
  references only**, never embed.

## Per-asset record (required before use)
source · URL/identifier · license · tissue · species · stain/method · magnification ·
structures shown · intended design use · reuse restriction · direct-use vs design-reference.

## Species/model tagging
Every reference must be tagged by species (human / rat / mouse) and model (tissue / cell line
/ 3D model) so it is applied only to the matching B1 scene — e.g. a human-skin H&E image
informs the CONTEXTUAL scaffold, not the ex-vivo rat-skin permeation scene.
