# Profile B — Precipitation Analysis

Machine-readable: `data/profile-b-precipitation-registry.json`.

## Six distinct phenomena (not interchangeable)
1. precipitation of the intact nanoparticle system
2. precipitation of **released** celastrol
3. crystallization **within** the carrier
4. aggregation of nanoparticles
5. sedimentation of particles
6. chemical degradation

## P1 (Chen) evidence per phenomenon
| Phenomenon | Status | Basis |
|---|---|---|
| Intact-NP precipitation | not investigated | — |
| **Released**-celastrol precipitation | inferred / possible after release, dilution | celastrol poorly soluble → may supersaturate once released into aqueous skin/receptor fluid; **no onset-time experiment** |
| Crystallization **within** carrier | prevented by encapsulation | DSC: celastrol amorphous in NLC |
| NP aggregation | not investigated | no size-vs-time |
| Sedimentation | not investigated | — |
| Chemical degradation | not measured for this formulation | celastrol instability known generally |

## Precipitation logic and the honest limit
While celastrol is amorphous/encapsulated, precipitation and crystallization are
**suppressed**. Precipitation is a **post-release**, dilution/pH-dependent phenomenon of
the **free** drug. **No compatible time-to-precipitation data exist for any Profile-B
preset.**

**Therefore the model may express precipitation only as a RISK CATEGORY / solubility-
margin indicator — never a deterministic event time.** We do **not** state "celastrol
precipitates after N hours."

## Recommended precipitation model
**Type A/B only.** A solubility/supersaturation model (type E) is **not** justified — no
dissolution, concentration, pH, or nucleation dataset for celastrol in the relevant
environments has been opened.
