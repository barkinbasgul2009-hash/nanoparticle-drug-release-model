# Stage-2 Supplementary-Materials Checklist

Model-critical values often live in SI, not the main PDF. Request these SEPARATELY:

| Source | Main PDF | Supplement needed | Why |
|---|---|---|---|
| C1 Chen 2024 | yes | **Supporting Information (raw spatial profiles / figures source data)** | size-dependent depth curves are likely only in SI |
| E1 Doxil (FDA) | Label | **Clinical Pharmacology & Biopharmaceutics review** (separate PDF) | PK parameters, encapsulated-vs-free |
| F1 Abraxane (FDA) | Label | **Clinical Pharmacology review** | PK, dissociation |
| B1/B2 celastrol NLC | yes | SI tables (release/permeation raw data) if present | time-resolved release + retention |
| D3 Pluen 2001 (PNAS) | yes | SI if present | interstitial diffusion coefficients |
| E5 Charrois 2004 | yes | SI if present | release-rate vs PK data tables |

Rule: an article PDF alone is often insufficient — check each publisher page for a
"Supporting Information"/"Supplementary" link and download it too.
