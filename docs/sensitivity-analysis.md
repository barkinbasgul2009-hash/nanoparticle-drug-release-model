# Sensitivity Analysis (plan)

Status: plan only.

For each qualified profile, quantify how outputs (penetration depth, tissue AUC,
Cmax) respond to each parameter (D_tissue, k_e, geometry, release parameters,
coupling terms). Identify which parameters dominate output uncertainty and which
are non-identifiable from the available data. Report as tornado/one-at-a-time and,
where justified, global (variance-based) indices.

For the current ILLUSTRATIVE_ONLY generic model, sliders already provide informal
interactive sensitivity; formal analysis attaches to named-tissue profiles.
